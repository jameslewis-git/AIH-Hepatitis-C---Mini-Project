🩸 The Problem

Hepatitis C Kills Silently

Hepatitis C virus (HCV) infects the liver and progresses silently over decades. An estimated 58 million people worldwide are living with chronic HCV infection (WHO, 2023), and most don't know it.

Left untreated, HCV progresses from inflammation → fibrosis → cirrhosis → liver cancer. Traditional staging requires an invasive liver biopsy — a painful procedure with risk of bleeding and complications.

→ This project proposes a non-invasive ML alternative using routine blood panel values collected during standard checkups.

🫀 Disease Progression

5 Stages the Model Classifies

HCV damage advances through distinct, measurable stages. Each stage produces a characteristic pattern in liver enzyme and metabolic blood markers, which the AI model learns to recognize.

🟢 Blood Donor
All liver markers within normal ranges. No HCV activity detected. Patient is a safe blood donor.
🟡 Suspect Donor
Borderline elevations in enzymes (ALT, GGT). Not confirmable as donor. Monitoring required.
🟠 Hepatitis
Active viral inflammation. Elevated ALT, AST, GGT. Liver is under active immune attack.
🔴 Fibrosis
Scar tissue forming (collagen deposit). Low ALB and CHE signal reduced liver function.
🔴 Cirrhosis
Advanced scarring. Critically low ALB, CHE, CHOL. High BIL, GGT. Organ failure risk.

WHY THIS MATTERS
A liver biopsy costs $1,500–$5,000 and carries real medical risk. These same 12 markers cost <$50 and are already collected during routine checkups — meaning AI staging could be deployed with zero additional cost to the patient.
🤖 The AI Engine

How the Model Works

1. XGBoost (Extreme Gradient Boosting)
XGBoost builds an ensemble of decision trees sequentially. Each tree corrects errors from the previous one, minimizing a loss function using gradient descent. This makes it exceptionally good at tabular medical data with imbalanced classes.
2. Training vs Random Forest
Both Random Forest and XGBoost are trained on the same dataset. The one with higher macro-F1 score is automatically selected — ensuring the best model is always deployed.
3. Macro-F1 as the Evaluation Metric
Regular accuracy fails with imbalanced classes (e.g., few Cirrhosis vs many Blood Donors). Macro-F1 averages precision & recall equally across all 5 classes, penalizing models that ignore minority stages.
4. Output: Probability Distribution
Instead of a single label, the model uses predict_proba() to return a confidence score for each stage, giving clinicians actionable probabilistic insight rather than a binary decision.

2. Preprocessing & Normalization
ETL Pipeline
Clinical missing values (e.g. ALB, CHOL) are filled using median imputation to resist outlier distortion. Biological sex is label-encoded into numeric binaries, and all 10 continuous enzyme features are standardized using StandardScaler (μ=0, σ=1) to eliminate variance scale disparities.
SimpleImputer(median) LabelEncoder(Sex) StandardScaler(z-score) Zero Data Leakage
INPUT: Incomplete raw records + categorical Sex
OUTPUT: Standardized numerical feature array

↓
3. XGBoost Gradient Boosting Engine
Classifier Engine
XGBoost sequentially builds an ensemble of regularized decision trees, minimizing multi-class softprob loss via gradient descent. The algorithm is tuned against Random Forest and evaluated using Macro-F1 score to ensure rare disease classes (Suspect, Fibrosis) receive equal classification priority as healthy donors.
Extreme Gradient Boosting Objective: multi:softprob Macro-F1 Optimization Stratified 80/20 Train-Test
INPUT: Scaled 12-marker vector inputs
OUTPUT: 5-class calibrated probability distribution

Model Bundle (.pkl)
